# Изменения

## 1.1.0 — 2026-10-17

- Название модуля — «[SH] ИИ чат с ролями»; порядок в списке модулей `MODULE_SORT = 1006`.
- **Ответ печатается по ходу**: новое действие `shef:toolsaiassistant.chat.stream`
  (поток `text/event-stream`, `Chat\StreamResponse` + `Chat\StreamEvents`), модель —
  `LlmService::stream()` shef.toolsai. Права, sessid, проверка роли, лимит частоты,
  квота и журнал расхода — как у ответа одним куском; отказ до потока — обычной
  ошибкой ajax, обрыв посреди — «Ответ модели оборвался». Окно — `stream.js` (fetch).
  Действие `answer` (одним JSON) оставлено.
- **Оценки ответов «Полезно / Не помогло»** (как было в чате shef.toolsai): действие
  `rate`, таблица `shef_toolsaiassistant_feedback` (сотрудник, роль, чат, вопрос и
  ответ кратко, оценка, комментарий, время), не больше 30 оценок в минуту.
  Страница «Оценки ответов» `/shef/toolsaiassistant/feedback/` и право «Смотреть
  оценки ответов» (`feedback.view`; администратору — всегда, в заготовки ролей не
  входит). Таблица создаётся при установке и при первой оценке после обновления.
- Настройка «Где показывать чат»: поле крупнее (8 строк, 80 знаков); **сохранённое
  пустое значение — чат нигде** (раньше пусто значило «/crm/ и вид «ИИ»»).
  Умолчание `/crm/` и `/shef/toolsai/view/` — по-прежнему в `default_option.php`.
- Перенос прав из shef.toolsai (`Access\LegacyRights`) оставлен.

## 1.0.0 — 2026-10-16

Первый выпуск: чат ИИ-помощника вынесен из shef.toolsai (1.44.0–1.49.0) в отдельный модуль.

- Панель справа, кнопка «✦ ИИ: чат», `window.ShefAiChat.open({entityTypeId, id, title})`
  и действие строки «✦ Спросить ИИ» — перенос `Assistant\SidePanel` shef.toolsai без смены смысла.
- Окно чата — JS-расширение модуля `shef.toolsaiassistant.chat` (чистый BX, без Nuxt);
  ответ — контроллер `shef:toolsaiassistant.chat.answer` вместо `endpoint/kb.php` shef.toolsai.
- Шесть ролей помощника в реестре промптов shef.toolsai (событие `OnPromptRegistryBuild`):
  Помощник менеджера (по умолчанию), Контроль руководителя, Аналитик качества сделки,
  Узкие места, Наставник по звонкам и переписке, Клиентский опыт.
- Свои права на `ui.accessrights.v2`: «Пользоваться чатом» и право на каждую роль;
  заготовки ролей доступа «Продавец» и «Руководитель продаж».
- Переключатель ролей — только открытые; выбор запоминается на сотрудника и чат
  (таблица `shef_toolsaiassistant_role_choice`); право роли проверяется на каждом ответе.
- От shef.toolsai — только публичный API 1.50.0: `LlmService`, `PromptService`
  (место `PLACE_ASSISTANT`), `RecordService`.
- «✦ Спросить ИИ» в меню строки вида «ИИ» — событием `shef.toolsai:OnViewRowActionsBuild`.
- Перенос прав чата shef.toolsai (`assistant.use`, `assistant.panel`) в роль доступа
  «Чат (перенос из shef.toolsai)» при установке.
- Контекст ответа: текст роли + история записи (`RecordService::get`, права CRM) +
  статьи `shef.toolsaikb`, если модуль есть. Модель, квота и журнал расхода — shef.toolsai
  (категория расхода `assistant`).
- Ограничение частоты: не больше N ответов модели на сотрудника в минуту (настройка
  `CHAT_ratelimit`, по умолчанию 10; отказ с кодом `rate`).
- Порядок выкладки: сначала shef.toolsai 1.50.0, потом этот модуль.
