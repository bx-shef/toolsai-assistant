# shef.toolsaiassistant — чат ИИ-помощника с ролями

Модуль коробочного Битрикс24. Даёт сотрудникам **чат ИИ-помощника панелью справа**
в CRM: кнопка «✦ ИИ: чат» и действие «✦ Спросить ИИ» в строке записи. Помощник
отвечает по **истории записи CRM** (звонки, письма, чаты, дела, комментарии) и по
**статьям базы знаний**, если стоит модуль `shef.toolsaikb`.

Помощник работает в одной из **шести ролей** — акцент на анализе работы
сотрудников, узких местах и качестве ведения сделки:

| роль | для чего |
|---|---|
| Помощник менеджера (по умолчанию) | что происходит, что мешает, следующий шаг, черновик письма |
| Контроль руководителя | как сотрудник ведёт сделку: скорость реакции, регламент, риски |
| Аналитик качества сделки | чек-лист ведения сделки и оценка 1–10 |
| Узкие места | где сделка теряет время и кто её держит |
| Наставник по звонкам и переписке | разбор разговоров и переписки, готовые фразы |
| Клиентский опыт | сделка глазами клиента: ожидание, усилия, риск ухода |

Кто пользуется чатом и **какие роли кому открыты** — решает администратор на
странице «Права доступа» (штатный `ui.accessrights`): продавцу роль руководителя не
дают. Сотрудник видит в переключателе только открытые роли, выбор запоминается на
него и на чат, а сервер проверяет право роли на каждом ответе.

Модель, месячная квота и журнал расхода — у модуля [shef.toolsai](https://github.com/bx-shef/toolsai):
тексты ролей правятся в его «Библиотеке промптов», модель — направление «Чат
ИИ-помощника» его настроек.

## Установка

Нужны: Битрикс24 (коробка) с модулями `crm` и `ui`, PHP 8.2+, UTF-8,
[shef.options](https://github.com/bx-shef/options) 3.0+,
[shef.problems](https://github.com/bx-shef/problems) 2.0+,
[shef.toolsai](https://github.com/bx-shef/toolsai) 1.50.0+. По желанию —
[shef.toolsaikb](https://github.com/bx-shef/toolsai-kb) (статьи базы знаний).

1. Архив `shef.toolsaiassistant.zip` (собирает `./build.sh`) распаковать в
   `bitrix/modules/` или `composer require bxshef/toolsai-assistant`.
2. «Настройки → Модули» — установить «[SH] ИИ-помощник: чат с ролями».
3. Открыть `/shef/toolsaiassistant/rights/` и назначить роли доступа «Продавец» и
   «Руководитель продаж» отделам или сотрудникам.
